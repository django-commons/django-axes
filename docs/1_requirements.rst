Requirements
============

Axes requires Django 5.2 or above and Python 3.11 or above.

Refer to the project source code repository in
`GitHub <https://github.com/django-commons/django-axes/>`_ and see the
`pyproject.toml file <https://github.com/django-commons/django-axes/blob/master/pyproject.toml>`_ and
`Python package definition <https://github.com/django-commons/django-axes/blob/master/setup.py>`_
to check if your Django and Python version are supported.

The `GitHub Actions builds <https://github.com/django-commons/django-axes/actions>`_
test Axes compatibility with the Django master branch for future compatibility as well.
